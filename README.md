# DSA Problems Solver in Java

A simple menu-driven Java program that implements commonly used Data Structures and Algorithms problems for practicing programming and problem-solving skills.

## Features

### Arrays
- Find Largest Element
- Find Smallest Element
- Reverse an Array
- Find Sum of Array
- Find Second Largest Element

### Searching
- Linear Search
- Binary Search

### Sorting
- Bubble Sort

### Strings
- Reverse a String
- Check Palindrome

## Technologies Used

- Java
- Arrays
- Strings
- Loops
- Methods
- Searching Algorithms
- Sorting Algorithms
- Scanner
